📜 script.md Otomatik Seslendirme Alanı

Flow videoları tamamlandığında script.md içindeki seslendirme metinleri otomatik olarak buraya (veya bağladığınız kendi sitenize) aktarılır.

Hazır. Flow videoları bittiğinde veya "script.md Gönder" butonuna bastığınızda seslendirme otomatik başlar.

🔗 Kendi Siteniz İçin Tam Otomasyon Kancası (İsteğe Bağlı)

Sitenizde hiçbir kod değiştirmeseniz bile uygulama metin kutusunu bulup doldurur ve indirilen/çalınan .mp3/.wav seslerini otomatik yakalar. Ancak %100 doğrudan bağlantı isterseniz sitenize şu 5 satırı ekleyebilirsiniz:

// 1. Masaüstü uygulamasından script.md metnini alma: window.startVoiceover = async function(fullText, scenes) { console.log("Gelen script.md:", fullText, scenes); // Kendi ses üretim fonksiyonunuzu çağırın: const audioUrl = await kendiTtsFonksiyonunuz(fullText); // 2. Üretilen sesi doğrudan CapCut Timeline'ına gönderme: const a = document.createElement('a'); a.href = audioUrl; a.download = 'seslendirme.mp3'; a.click(); };
